# Słownik odpowiedników usług chmurowych

| Rodzaj usługi | AWS | Azure | Google Cloud |
|---|---|---|---|
| Maszyny wirtualne (IaaS) | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Aplikacje webowe (PaaS) | AWS Elastic Beanstalk | Azure App Service | Google App Engine |
| Funkcje bezserwerowe (FaaS) | AWS Lambda | Azure Functions | Cloud Run functions |
| Obiektowa pamięć masowa (Storage) | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Relacyjne bazy danych (DBaaS) | Amazon RDS | Azure SQL Database | Cloud SQL |
